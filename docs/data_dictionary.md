# Data Dictionary (v1)

Business definitions of the analytical marts built from real public data.
Synthetic transactional tables (customers, merchants, payments, loyalty) are
added in Phase 3 and documented in v2. Implemented in Phase 5 (dbt).

## Naming conventions

| Pattern | Meaning | Example |
|---|---|---|
| `snake_case` | All tables and columns | `country_name` |
| `dim_` / `fact_` | Dimension / fact table | `dim_country` |
| `*_key` | Surrogate key generated by the warehouse | `country_key` |
| `*_code` | Natural code from a source or standard | `country_iso3` |
| `*_pct` | Percentage, 0–100 | `internet_users_pct` |
| `*_usd` | US dollars | `gdp_current_usd` |
| `*_per_100` | Per 100 people | `mobile_subscriptions_per_100` |
| `is_*` | Boolean flag | `is_projection` |

## dim_country

**Grain:** one row per African country in scope (54 rows). **Source:** reference file + World Bank countries.

| Column | Type | Description |
|---|---|---|
| `country_key` | integer | Surrogate key |
| `country_iso3` | text(3) | ISO 3166-1 alpha-3 code. Natural key. |
| `country_iso2` | text(2) | ISO 3166-1 alpha-2 code (Namibia = `NA`) |
| `country_name` | text | Display name (e.g. "DR Congo") |
| `country_name_wb` | text | World Bank official name (e.g. "Congo, Dem. Rep.") |
| `au_region` | text | African Union region: Northern, Western, Central, Eastern, Southern |
| `wb_region_name` | text | World Bank region (descriptive only, never used to define Africa) |
| `income_group_name` | text | Current World Bank income group (history kept via dbt snapshot, Phase 5) |
| `capital_city` | text | Capital city |
| `latitude`, `longitude` | numeric | Capital city coordinates (for maps) |

## dim_indicator

**Grain:** one row per indicator concept. **Source:** concept table in the STM.

| Column | Type | Description |
|---|---|---|
| `indicator_key` | integer | Surrogate key |
| `indicator_code` | text | AfriPulse concept code (e.g. `gdp_real_growth_pct`) |
| `indicator_name` | text | Human-readable name |
| `unit` | text | `%`, `USD`, `persons`, `years`, `per 100 people`... |
| `theme` | text | `economy`, `demography`, `connectivity`, `financial_inclusion` |
| `default_source_id` | text | Source used by dashboards unless another is chosen |
| `higher_is_better` | boolean | For colour scales in dashboards (null where not meaningful) |

## fact_economic_indicators

**Grain:** one row per **country × year × indicator × source**.

Example: Kenya, 2023, `gdp_real_growth_pct`, `imf_weo` → 5.7.
Kenya, 2023, `gdp_real_growth_pct`, `worldbank_wdi` → a separate row.

**Why this grain:** sources disagree (F-IMF-9), so values are never averaged
or overwritten; each source keeps its own row. Long format means a new
indicator needs no schema change.

| Column | Type | Description |
|---|---|---|
| `country_key` | integer | FK → `dim_country` |
| `indicator_key` | integer | FK → `dim_indicator` |
| `year` | integer | Calendar year of the observation |
| `source_id` | text | `worldbank_wdi`, `imf_weo`, `un_wpp`, `findex` |
| `source_release` | text | e.g. `WEO-2026-10`, `WPP2024` |
| `value` | numeric | The value, in the indicator's unit |
| `is_projection` | boolean | True for forecasts (IMF, UN WPP) |
| `is_default_source` | boolean | True if `source_id` is the indicator's default |
| `sources_disagree` | boolean | True if another source differs by > 2 percentage points (growth/inflation) |

**Primary key:** (`country_key`, `indicator_key`, `year`, `source_id`).

## fact_digital_adoption

**Grain:** one row per **country × year**, default source only, actual values only (no projections).

**Why a second, wide fact:** dashboards comparing several connectivity and
financial-inclusion measures side by side are far simpler with one column per
measure. It is derived from `fact_economic_indicators`, so the numbers always agree.

| Column | Type | Description |
|---|---|---|
| `country_key` | integer | FK → `dim_country` |
| `year` | integer | Calendar year |
| `internet_users_pct` | numeric | Individuals using the internet (%) |
| `mobile_subscriptions_per_100` | numeric | Mobile subscriptions per 100 people (can exceed 100: multiple SIMs) |
| `fixed_broadband_per_100` | numeric | Fixed broadband subscriptions per 100 people |
| `account_ownership_pct` | numeric | Adults with any account (%), survey years only |
| `mobile_money_account_pct` | numeric | Adults with a mobile money account (%), survey years only |
| `population_total` | numeric | Mid-year population (for weighting averages) |
| `latest_internet_year` | integer | Most recent year with internet data for this country (F9) |

**Primary key:** (`country_key`, `year`).

## Reporting rules

| Rule | Reason |
|---|---|
| Africa-wide averages are **population-weighted** and state **country coverage** (e.g. "51 of 54") | Selection bias toward better-documented countries (F15) |
| Survey-based measures are shown for survey years only; never interpolated silently | F7 |
| Countries never surveyed show "no data", never 0 | F8 |
| Projections are visually distinguished from actuals | F-IMF-5, F-UN-10 |
| Values with `sources_disagree = true` carry a warning | F-IMF-9 |
