# Data Dictionary (v2)

Business definitions of the analytical marts (schema `marts`). Built by dbt in
Phase 5 from the `raw` and `raw_synthetic` layers. Design and diagram:
[warehouse_erd.md](architecture/warehouse_erd.md); rationale:
[ADR 0002](adr/0002-dimensional-model.md).

> Tables marked **SYNTHETIC** contain generated data calibrated to real
> statistics. They never describe real people, merchants or transactions
> ([synthetic_data.md](synthetic_data.md)).

**Changes from v1:** surrogate keys are now md5 hash keys (text), except
`dim_date` (integer `YYYYMMDD`); added `dim_date`, `dim_source`,
`dim_payment_method`, `dim_customer`, `dim_merchant` and the three transaction facts;
unknown-member rows (`'-1'`) added to every dimension.

## Naming conventions

| Pattern | Meaning | Example |
|---|---|---|
| `snake_case` | All tables and columns | `country_name` |
| `dim_` / `fact_` | Dimension / fact table | `dim_country` |
| `*_key` | Surrogate key generated by the warehouse | `country_key` |
| `*_id`, `*_code` | Natural key from a source, a standard or the generator | `customer_id`, `country_iso3` |
| `*_pct` | Percentage, 0–100 | `internet_users_pct` |
| `*_usd` | US dollars | `amount_usd` |
| `*_per_100` | Per 100 people | `mobile_subscriptions_per_100` |
| `*_ts` | Timestamp (local time) | `txn_ts` |
| `is_*`, `has_*`, `accepts_*` | Boolean flag | `is_projection` |

## Dimensions

### dim_country

**Grain:** one row per African country in scope (54) + unknown member. **Source:** reference file + World Bank countries. **SCD:** Type 1 (history via dbt snapshot).

| Column | Type | Description |
|---|---|---|
| `country_key` | text | Surrogate key (hash of `country_iso3`) |
| `country_iso3` | text(3) | ISO 3166-1 alpha-3 code. Natural key. |
| `country_iso2` | text(2) | ISO 3166-1 alpha-2 code (Namibia = `NA`) |
| `country_name` | text | Display name (e.g. "DR Congo") |
| `country_name_wb` | text | World Bank official name (e.g. "Congo, Dem. Rep.") |
| `au_region` | text | African Union region: Northern, Western, Central, Eastern, Southern |
| `wb_region_name` | text | World Bank region (descriptive only, never used to define Africa) |
| `income_group_name` | text | Current World Bank income group |
| `capital_city` | text | Capital city |
| `latitude`, `longitude` | numeric | Capital city coordinates (for maps) |
| `is_synthetic_market` | boolean | True for the 8 countries with synthetic transaction data |

### dim_indicator

**Grain:** one row per indicator concept. **Source:** concept table in the STM (dbt seed).

| Column | Type | Description |
|---|---|---|
| `indicator_key` | text | Surrogate key |
| `indicator_code` | text | AfriPulse concept code (e.g. `gdp_real_growth_pct`) |
| `indicator_name` | text | Human-readable name |
| `unit` | text | `%`, `USD`, `persons`, `years`, `per 100 people`... |
| `theme` | text | `economy`, `demography`, `connectivity`, `financial_inclusion` |
| `default_source_id` | text | Source used by dashboards unless another is chosen |
| `higher_is_better` | boolean | For colour scales (null where not meaningful) |

### dim_source

**Grain:** one row per data source. **Source:** `config/sources.yml` (dbt seed).

| Column | Type | Description |
|---|---|---|
| `source_key` | text | Surrogate key |
| `source_id` | text | `worldbank_wdi`, `imf_weo`, `un_wpp`, `findex`, `synthetic` |
| `provider` | text | World Bank, IMF, United Nations, AfriPulse generator |
| `licence` | text | Licence of the source data |
| `is_synthetic` | boolean | True only for the generator |

### dim_date

**Grain:** one row per calendar day, 2019-01-01 to 2026-12-31. **Source:** generated by dbt.

| Column | Type | Description |
|---|---|---|
| `date_key` | integer | `YYYYMMDD`, e.g. `20251231` |
| `calendar_date` | date | The date |
| `year`, `quarter`, `month`, `day_of_month` | integer | Calendar parts |
| `month_name`, `day_name` | text | e.g. "December", "Friday" |
| `iso_week` | integer | ISO week number |
| `is_weekend` | boolean | Saturday or Sunday |
| `is_month_end_window` | boolean | Day 25 or later (salary period, used in synthetic patterns) |

### dim_payment_method

**Grain:** one row per payment method. **Source:** dbt seed.

| Column | Type | Description |
|---|---|---|
| `payment_method_key` | text | Surrogate key |
| `payment_method_code` | text | `cash`, `card`, `mobile_money`, `bank_transfer` |
| `payment_method_name` | text | Display name |
| `is_digital` | boolean | False only for cash |

### dim_customer (SYNTHETIC)

**Grain:** one row per synthetic customer + unknown member. **Source:** `raw_synthetic.customers`. **SCD:** Type 1.

| Column | Type | Description |
|---|---|---|
| `customer_key` | text | Surrogate key |
| `customer_id` | text | Generator ID, e.g. `CUS-000123` |
| `country_iso3`, `city` | text | Home market (attribute, not a foreign key: no snowflake) |
| `gender` | text | `female`, `male` |
| `age_band` | text | `18-24`, `25-34`, `35-44`, `45-54`, `55+` |
| `signup_date` | date | Date the customer joined |
| `has_mobile_money`, `has_bank_account` | boolean | Account ownership (calibrated to Findex) |
| `is_loyalty_member` | boolean | Enrolled in the loyalty programme |

### dim_merchant (SYNTHETIC)

**Grain:** one row per synthetic merchant + unknown member. **Source:** `raw_synthetic.merchants`. **SCD:** Type 1.

| Column | Type | Description |
|---|---|---|
| `merchant_key` | text | Surrogate key |
| `merchant_id`, `merchant_name` | text | Generator ID and name |
| `country_iso3`, `city` | text | Location (attribute) |
| `category` | text | `grocery`, `restaurant`, `pharmacy`, `fuel`, `clothing`, `airtime_data`, `electronics`, `utilities` |
| `accepts_card`, `accepts_mobile_money` | boolean | Accepted payment methods |
| `onboard_date` | date | Date the merchant joined |

## Facts

### fact_economic_indicators

**Grain:** one row per **country × year × indicator × source** (latest release of each source). **Measure additivity:** non-additive.

| Column | Type | Description |
|---|---|---|
| `country_key` | text | FK → `dim_country` |
| `indicator_key` | text | FK → `dim_indicator` |
| `source_key` | text | FK → `dim_source` |
| `year` | integer | Year of the observation |
| `source_release` | text | e.g. `WEO-2026-10`, `WPP2024`, `FINDEX2025` |
| `value` | numeric | Value in the indicator's unit (units standardised: % as 0–100, counts absolute) |
| `is_projection` | boolean | True for forecasts (IMF, UN WPP) |
| `is_default_source` | boolean | True if this source is the indicator's default |
| `sources_disagree` | boolean | True if another source differs by more than 2 percentage points |

**Primary key:** (`country_key`, `indicator_key`, `source_key`, `year`).

### fact_digital_adoption

**Grain:** one row per **country × year**; default sources, actuals only. Derived from `fact_economic_indicators`.

| Column | Type | Description |
|---|---|---|
| `country_key` | text | FK → `dim_country` |
| `year` | integer | Calendar year |
| `internet_users_pct` | numeric | Individuals using the internet (%) |
| `mobile_subscriptions_per_100` | numeric | Mobile subscriptions per 100 people (can exceed 100: several SIMs) |
| `fixed_broadband_per_100` | numeric | Fixed broadband subscriptions per 100 people |
| `account_ownership_pct` | numeric | Adults with any account (%), survey years only |
| `mobile_money_account_pct` | numeric | Adults with a mobile money account (%), survey years only |
| `population_total` | numeric | Mid-year population (for weighting averages) |
| `latest_internet_year` | integer | Most recent year with internet data for this country (F9) |

**Primary key:** (`country_key`, `year`).

### fact_retail_transactions (SYNTHETIC)

**Grain:** one row per **retail purchase**. **Load:** incremental.

| Column | Type | Description |
|---|---|---|
| `txn_id` | text | Degenerate dimension; primary key |
| `date_key` | integer | FK → `dim_date` |
| `country_key` | text | FK → `dim_country` (customer's market) |
| `customer_key` | text | FK → `dim_customer` |
| `merchant_key` | text | FK → `dim_merchant` |
| `payment_method_key` | text | FK → `dim_payment_method` |
| `txn_ts` | timestamp | Local date and time |
| `amount_usd` | numeric(12,2) | Purchase amount (additive) |
| `item_count` | integer | Items in the basket (additive) |

### fact_mobile_money (SYNTHETIC)

**Grain:** one row per **mobile money wallet transaction**. **Load:** incremental.

| Column | Type | Description |
|---|---|---|
| `mm_txn_id` | text | Degenerate dimension; primary key |
| `date_key` | integer | FK → `dim_date` |
| `country_key` | text | FK → `dim_country` |
| `customer_key` | text | FK → `dim_customer` (wallet owner / sender) |
| `counterparty_customer_key` | text | FK → `dim_customer` (P2P recipient; `'-1'` otherwise). Role-playing dimension. |
| `merchant_key` | text | FK → `dim_merchant` (merchant payments; `'-1'` otherwise) |
| `retail_txn_id` | text | The matching retail purchase, for merchant payments |
| `txn_type` | text | `p2p_transfer`, `cash_in`, `cash_out`, `airtime_purchase`, `bill_payment`, `merchant_payment` |
| `status` | text | `completed`, `failed` |
| `txn_ts` | timestamp | Local date and time |
| `amount_usd`, `fee_usd` | numeric(12,2) | Amount and fee (additive; filter `status = 'completed'` for value moved) |

### fact_loyalty_transactions (SYNTHETIC)

**Grain:** one row per **loyalty event** (points earned or redeemed). **Load:** incremental.

| Column | Type | Description |
|---|---|---|
| `event_id` | text | Degenerate dimension; primary key |
| `date_key` | integer | FK → `dim_date` |
| `country_key` | text | FK → `dim_country` |
| `customer_key` | text | FK → `dim_customer` |
| `retail_txn_id` | text | Purchase that earned the points (earn events) |
| `event_type` | text | `earn`, `redeem` |
| `points_earned` | integer | Points earned (0 for redemptions; additive) |
| `points_redeemed` | integer | Points redeemed (0 for earnings; additive) |
| `balance_after` | integer | Balance after the event. **Semi-additive: never sum over time** |
| `event_ts` | timestamp | Local date and time |

## Reporting rules

| Rule | Reason |
|---|---|
| Africa-wide averages are **population-weighted** and state **country coverage** (e.g. "51 of 54") | Selection bias toward better-documented countries (F15) |
| Survey-based measures are shown for survey years only; never interpolated silently | F7 |
| Countries never surveyed show "no data", never 0 | F8 |
| Projections are visually distinguished from actuals | F-IMF-5, F-UN-10 |
| Values with `sources_disagree = true` carry a warning | F-IMF-9 |
| Synthetic dashboards carry a visible "SYNTHETIC DATA" label | Project rule |
| Loyalty balances: latest per customer, then sum; never sum over time | Semi-additive measure |
